Focus Bomber 개인정보처리방침

최종 수정일: 2026년 10월 21일

Focus Bomber는 사용자가 직접 지정한 웹사이트의 이용시간을 제한하는 Chrome 확장 프로그램입니다.

처리하는 정보

확장 프로그램은 다음 정보를 사용자의 브라우저 내부 chrome.storage.local 저장소에 저장합니다.

  • 사용자가 설정한 웹사이트 도메인
  • 사이트별 하루 제한시간과 활성화 상태
  • 날짜별 누적 사용시간과 제한 초과 상태

페이지 요소를 폭격 애니메이션 대상으로 표시하기 위해 설정된 사이트의 문서 구조를 브라우저 안에서 일시적으로 처리합니다. 페이지 내용은 저장하거나 외부로 전송하지 않습니다.

정보의 전송 및 공유

Focus Bomber는 서버를 운영하지 않으며 저장된 설정, 사용 기록, 방문 기록 또는 페이지 내용을 개발자나 제3자에게 전송하지 않습니다. 정보를 판매하거나 광고, 분석, 신용평가 또는 맞춤형 광고에 사용하지 않습니다.

보관 및 삭제

설정과 사용 기록은 사용자의 브라우저에 보관됩니다. 팝업에서 설정 또는 오늘 기록을 삭제하거나 Chrome에서 확장 프로그램을 제거하면 관련 로컬 데이터도 삭제할 수 있습니다. 브라우저의 동기화 대상에는 포함되지 않습니다.

권한 사용 목적

  • storage: 사이트 설정과 날짜별 사용시간을 로컬에 보관합니다.
  • scripting: 현재 사이트의 제한을 저장한 직후 타이머를 적용합니다.
  • offscreen: 애니메이션 중 항공기와 폭발 효과음을 재생합니다.
  • 사이트 접근 권한: 사용자가 선택한 사이트에서 타이머 및 애니메이션을 실행합니다.
